# Sayan Karmakar — Academic Website

Static four-page HTML/CSS/JavaScript academic website (Home, Research, About, Contact) with a downloadable CV.

## Publish with GitHub Pages

1. On GitHub, create a **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload the individual files in this folder to the repository root (not the folder itself).
3. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io`.

## Editing

- Text lives directly in `index.html`, `research.html`, `about.html` and `contact.html`.
- To update the CV, replace `Sayan_Karmakar_CV.pdf` (keep the same file name).
- To add a profile photo, put `photo.jpg` in the root and, in `index.html`, replace the `<div class="profile-card">…</div>` block with
  `<div class="image-frame"><img alt="Sayan Karmakar" src="photo.jpg" width="1152" height="1536"/></div>`.
